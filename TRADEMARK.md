## Why This Policy Exists

Open-source software and trademark protection serve different purposes.

The Apache License 2.0 ensures that Laurevine Loto's source code can be freely used, modified, and redistributed. Trademark protection ensures that the product's identity remains distinguishable.

Without these protections, unofficial forks could be distributed under the same name, using the same branding and visual identity, making it difficult for users to distinguish the official application from independent derivatives.

This policy protects the identity of Laurevine Loto while preserving the freedoms granted by its open-source license.

**The code is open. The brand is not.**
